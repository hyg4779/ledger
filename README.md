# 자산 가계부 (PWA)

수입·지출을 기록하고 월간·연간·전체 기간으로 돌아보는 가계부. 폰 홈 화면에 추가하면 앱처럼 열린다.

- Vite + React + TypeScript, 차트는 SVG로 직접 그림 (라이브러리 없음), 글꼴은 Pretendard
- `vite-plugin-pwa`로 오프라인 동작·홈 화면 설치 지원
- 데이터는 **기기 안 IndexedDB**에만 저장 (서버 없음). 설정 → 백업에서 JSON/CSV 내보내기

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 생성 (tsc 타입 검사 포함)
npm run preview    # 빌드 결과 확인 http://localhost:4173
```

아이콘을 바꿨다면 `scripts/icon.svg` 수정 후 `node scripts/make-icons.mjs`.

PowerShell 5.1은 `&&`를 지원하지 않으니 명령을 `;`로 잇는다 (예: `cd ledger; npm run preview`).

## 배포 (GitHub Pages)

PWA(서비스 워커)는 **HTTPS 주소**에서만 동작하므로 GitHub Pages에 올린다.
`.github/workflows/deploy.yml`이 `main`에 푸시될 때마다 빌드·배포한다.

이 폴더는 상위 저장소(습관 앱)와 별개로, `git subtree`로 `ledger/`만 따로 GitHub 저장소에 올린다.
상위 폴더에서 변경을 커밋한 뒤:

```powershell
git subtree push --prefix ledger ledger main
```

- 처음 한 번: GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정
- 주소: `https://<아이디>.github.io/<저장소>/` (`base: './'`라 하위 경로에서도 동작)
- 아이폰 Safari로 열고 공유 → **홈 화면에 추가** / 안드로이드 Chrome은 ⋮ → **앱 설치**

## 화면

연두·크림 톤의 카드형 디자인(라이트/다크), 하단 5탭 + 떠 있는 「＋ 기록하기」 버튼.

| 탭 | 내용 |
|---|---|
| 홈 | 이번 달 지출 대시보드(상위 5개 카테고리 + 기타 도넛, 지난달 같은 기간 대비), 남은 생활비 카드(예산 사용률·오늘 위치·오늘 포함 하루 사용 가능 금액), 수입과 저축, 최근 기록 |
| 기록 | 월별 수입·지출 기록 목록. 남은 돈/수입/지출 카드로 필터, 검색, 카테고리 필터 |
| 대출·이자 | 총 잔액·갚은 원금·이번 달 예상 이자/원금, 잔액 구성 도넛, 월별 납부 이자(대출별 기록 여부), 연간 이자 차트, 대출별 카드(만기 D-day, 1년 이내 경고), 납부 기록(이자→지출, 원금→잔액 차감) |
| 분석 › 월간 | 지난달 같은 기간 대비 지출, 일별 누적 지출 비교선, 카테고리 순위(예산 사용률) |
| 분석 › 연간 | 작년 같은 기간 대비, 월별 수입·지출 막대, 월별 저축액, 월별 요약표, 카테고리×월 히트맵 |
| 분석 › 전체 | 누적 저축 추이, 연도별 수입·지출, 연도별 요약표 |
| 설정 | 월 예산, 카테고리 추가·수정·숨김·순서·카테고리 예산, 테마, 백업/복원, 예시 데이터 |

## 데이터 주의

- 사파리 방문 기록·웹사이트 데이터를 지우거나 앱을 홈 화면에서 삭제하면 데이터도 사라진다 → 정기 백업 필요
- 내역이 있는 카테고리는 삭제하지 않고 숨긴다(과거 내역 표시 유지)
